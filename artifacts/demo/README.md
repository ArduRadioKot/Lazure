# Материалы демонстрации

Сюда кладётся видео работы приложения (или ссылка на него, если файл больше лимита GitHub) и исходные файлы, использованные в демо.

## Сценарий видео (3–5 минут)

1. Включён **авиарежим**: показываем, что сети нет.
2. Установка APK из Releases, первый запуск.
3. **Главная → Импорт** → выбор записи диалога (2–3 говорящих) → прогресс обработки.
4. Готовая расшифровка:
   - реплики разных говорящих с метками времени;
   - строка «Обработано за X с · RTF Y».
5. Воспроизведение:
   - подсветка текущей реплики;
   - переход к реплике по нажатию;
   - пометка «Перебивание» на наложениях.
6. Переименование говорящего и исправление текста реплики.
7. **Экспорт JSON** → открыть файл и показать схему `transcript / speaker_id / start_ms / end_ms / text`.
8. **Суммаризация** и **Спросить ИИ**: ответы локальной LLM со ссылками на таймкоды.
9. **Запись** из приложения → остановка → автоматическая обработка.
